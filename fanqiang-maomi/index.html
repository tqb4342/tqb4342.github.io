搜「翻墙软件猫咪」「小猫翻墙软件」的人，几乎都是同一个场景：朋友给推荐了个翻墙软件，说图标是只猫，让自己去搜。结果搜出来一堆猫咪加速器、猫咪 VPN，不知道哪个才是正主。

先把答案放这：你找的那只猫，是 Clash 系客户端。这是个统称，不是某一个软件——Clash 的图标就是一只猫，用的人多了，圈子里就叫它「猫咪」「小猫」。下面把这只猫的家谱、去哪下、订阅怎么导一次说完。

30 秒速答

  • 猫咪 = Clash 系翻墙客户端的统称，因为图标是猫
  • 电脑上主流的猫是 Clash Verge Rev，活跃维护，Windows / Mac / Linux 都有
  • 老牌的 Clash for Windows 也是猫，但 2023 年已停更删库，新机器别装了
  • 安卓的猫叫 ClashMetaForAndroid；iOS 没有正牌 Clash 客户端，一般用 Spectre 替代
  • 客户端免费，里面的节点要花钱（机场订阅，15 元/月起）
  • 下载只认 GitHub 官方仓库，别信搜索引擎广告里的「Clash 官网」

猫咪这个名字是怎么来的

Clash 是一个开源代理内核，2020 年前后在圈内火起来的时候，配套客户端 Clash for Windows 用了一只猫当图标——运行起来系统托盘里就卧着一只金色的猫。翻墙话题没法在朋友圈公开聊，大家就用暗语，「那个猫咪软件」「小猫怎么弄」说的全是它。

后来 Clash 原版内核停止维护，社区接着维护的分支叫 Mihomo（以前叫 Clash Meta），围绕它的客户端一只接一只出，图标不约而同全用猫。于是「猫咪」从一个软件的名字，变成了这一整类工具的统称。内核和客户端是什么关系、Mihomo 和 Clash 的区别，展开讲在 Mihomo 和 Clash 的区别 那篇。

上图是 Clash for Windows 时代的老截图：系统托盘里卧着两只猫，深色的代表代理关闭、浅色的代表代理开启——「猫咪软件」这个叫法，就是从这一只只托盘猫里传出来的。

现役猫咪客户端矩阵

2026 年还活着、值得装的猫，按平台整理：

客户端 平台 状态 适合谁
Clash Verge Rev Windows / Mac / Linux 活跃维护 电脑用户首选
Clash Party Mac / Windows 活跃维护 Mac 用户第二选择
Clash for Windows Windows 已停更（2023 删库） 只建议老用户过渡
ClashMetaForAndroid 安卓 活跃维护 安卓手机用户，配置流程看 安卓科学上网教程
Spectre iOS 活跃维护 iPhone 用户（非 Clash 系但同定位），配置流程看 iPhone 科学上网
sing-box 全平台 活跃维护 进阶玩家，通用代理内核

电脑端无脑选 Clash Verge Rev：下载安装导入订阅一条龙，中文界面，规则和分流功能齐全，完整流程在 Clash Verge 使用教程 里。Mac 用户可以对比下 Clash Party，同样能一键托管。

如果你装猫的年代比较早，用的是 Clash for Windows——它停更这件事很多老用户到现在都不知道，2023 年作者删库跑路，之后再没安全更新。它现在还能不能用、怎么迁移到新猫，专门写过 Clash for Windows 停更迁移指南。

想系统了解这套东西的完整体系（客户端、订阅、规则分流是什么关系），看 Clash 完全教程，那是这站的主力教程页。

去哪下载：只认 GitHub

所有猫咪客户端都开源，唯一的官方下载渠道是 GitHub 仓库的 Releases 页面。以 Clash Verge Rev 为例：仓库地址是 github.com/clash-verge-rev/clash-verge-rev，进 Releases 下载对应系统的安装包（Windows 选 .exe，Mac 选 .dmg）。

两个现实问题：

  1. GitHub 打不开、下载龟速。这是国内直连 GitHub 的老毛病。先解决网络再回来下载是正路——这本身就是个先有鸡还是先有蛋的问题，第一次装猫的人卡在这里最常见。解法是用机场官方提供的客户端下载指引，一枝红杏的用户可以直接用官方的下载与配置指引，绕开 GitHub 直连。
  2. 搜索引擎里的「Clash 官网」是假的。Clash 系工具没有官网、不收软件费。搜索结果前几位挂着广告标的「官网」，点进去要么捆绑全家桶，要么直接收你 99 元「激活费」。认准 github.com 域名，别的都不看。

猫有了，订阅怎么导

客户端装好只是个空壳，里面没有节点。节点来自机场订阅——在机场后台复制订阅链接，回到客户端：

上图就是机场后台的订阅页，一圈客户端各对应一条订阅链接，用 Clash 系客户端就复制 Clash 那一条。拿到的链接回到客户端：

  1. 打开「订阅」页面（Verge Rev 里叫「配置」）
  2. 粘贴订阅链接，点导入
  3. 回到节点页，选一个延迟低的节点
  4. 打开系统代理开关，托盘里的猫变色，搞定

选节点别只看名字谁顺眼——先跑一次延迟测速再挑，测速方法和「测出来全是超时怎么办」的排查，在 Clash 节点测速指南 里。订阅导入失败、更新报错、节点全是超时，这类问题八成出在订阅链接或网络上，排查方法在 Clash 订阅链接指南。还没有订阅的，可以看看一枝红杏这家，我用了七八年了，基本没啥问题。

免费的猫咪软件存在吗

存在，但形态和你想的不一样。猫咪客户端本身从来就是免费的——开源工具，谁都可以下载。收费的是里面的节点，也就是机场订阅。

于是市面上出现了两种「免费猫咪」：

  • 白嫖免费节点的猫：客户端里预置一堆免费节点，号称下载即用。节点质量基本没法看，速度 720P 都卡，失效极快，来源也不干净。
  • 山寨收费的猫：披个猫咪图标做营销，实际是套壳客户端收会员费，跑路重灾区。

真想一分钱不花先试试水，正确姿势在 免费翻墙靠谱吗 那篇里写透了——结论先给：能试，但别当长期方案，15 元月付机场就是「免费」和「能用」之间的那道墙。

常见问题

翻墙软件猫咪是哪个软件？

猫咪不是某一个软件的名字，而是对 Clash 系翻墙客户端的统称——因为 Clash 的图标是一只猫，大家搜「翻墙软件猫咪」「小猫翻墙」找的都是它。现在 Windows、Mac 上还在活跃维护的猫咪客户端主要是 Clash Verge Rev，手机端安卓用 ClashMetaForAndroid，iOS 用 Spectre 这类客户端代替。

猫咪软件去哪下载才安全？

只认 GitHub 官方仓库。Clash Verge Rev 的仓库是 github.com/clash-verge-rev/clash-verge-rev，进 Releases 页面下载对应系统的安装包。GitHub 打不开或速度慢，可以让家里网络先稳定科学上网，或用机场官方提供的客户端下载指引。搜索引擎广告位里的「Clash 官网」基本都是假的。

猫咪软件免费吗？

客户端本身免费开源，但它只是个壳，翻墙要用里面的节点，节点来自机场订阅，这部分要花钱。免费节点不是速度拉胯就是几天就跑路，稳定使用建议直接买一个月付机场，15 元左右就能起步。

小猫翻墙软件订阅链接怎么导入？

机场后台复制订阅链接，打开客户端进入「订阅」或「配置」页面，粘贴链接点导入，回到节点页选一个节点、打开系统代理开关就完成了。完整图文步骤看 Clash Verge 使用教程，订阅导入失败、更新报错的排查在 Clash 订阅链接指南里。

Clash for Windows 也是猫咪软件吗？

是，而且是当年最火的那只猫。但它在 2023 年已经删库停更，不再有安全更新，新电脑不建议再装，老用户建议迁移到 Clash Verge Rev。迁移方法和 CFW 还能不能继续用，看 Clash for Windows 停更专文。

山寨猫咪软件怎么辨别？

三条铁律：安装包只从 GitHub 官方仓库 Releases 下；名字花里胡哨、官网做得精美、还挂竞价广告的「Clash 官网」一律不信；装完杀毒软件报毒且无法说明来源的，直接删。Clash 系客户端全部开源，官方不会收你一分钱软件费。

总结

猫咪 = Clash 系客户端，这句黑话现在能听懂了。落地三步：GitHub 下 Clash Verge Rev，机场买个月付订阅，导入选节点开代理。第一次卡在 GitHub 下载的，用机场的官方下载指引绕过去；还在用停更 CFW 的老玩家，尽早迁到新猫。客户端是猫，线路才是命——节点选不对，再好的猫也翻不出去，机场怎么挑看 2026 翻墙机场推荐。
