sing-box 和 Clash 有什么区别？值得换吗？怎么用（2026 详解）

📚 本文是 科学上网完全指南（2026最新版） 系列教程之一。客户端选型、订阅导入、规则分流先看总览页，这篇只聊 sing-box：它到底是个什么、和 Clash 差在哪、你该不该碰它。

最近一年你在各种教程、客户端更新日志里，”sing-box”这个词出现得越来越频繁。很多人一头雾水：这又是个什么新东西？和我正在用的 Clash 是什么关系？是不是 Clash 的替代品？该不该换？

先给你 30 秒速答： sing-box 不是”又一个 Clash”，它是更底层的东西——一个通用代理内核。Clash 的 Mihomo 内核和它是同层面的”竞品内核”。你之所以老看到它，是因为越来越多新客户端开始拿它当底层引擎。如果你现在用 Clash 很顺手，不用换；sing-box 是进阶玩家想要的”装备升级”，不是新手入门必备。

下面把这个结论拆开讲清楚。

一、sing-box 是什么

sing-box 是一个开源项目，全称立意是「通用代理平台（universal proxy platform）」，由开发者 nekohasekai 在 2022 年发起，采用 GPLv3 许可。

关键要理解它「内核」的定位：sing-box 本身没有图形界面，也不是一个可以直接双击打开的 App。 它负责的是代理最核心的那些脏活累活——

  • 处理各种代理协议的入站（inbound）和出站（outbound）
  • 路由分流（哪些流量直连、哪些走代理）
  • DNS 解析与防污染
  • TUN 模式接管全局流量

这些，恰好和 Clash 的 Mihomo 内核干的活是同一类。所以准确的说法是：sing-box 和 Mihomo（Clash 内核）是同一个层面的东西，是”竞品内核”，而不是「Clash 之上的新东西」。

二、sing-box 和 Clash / Mihomo 到底差在哪

两者都是代理内核，但设计取向不一样，这个区别决定了它的受众：

维度 Clash / Mihomo sing-box
配置文件格式 YAML（人读友好） JSON（机器友好）
生态形态 内核 + 规则 + 客户端捆绑 更纯粹的内核，客户端另配
协议覆盖 主流协议为主 更广，新协议跟进更快
设计哲学 “带规则系统的全家桶” “模块化的通用核心”
典型用户 普通用户 + GUI 客户端 软路由/服务器进阶玩家 + 新客户端引擎

一句话概括：Clash 是”全家桶”，sing-box 是”更纯、更通用、更现代的内核”。

具体到你可能关心的一点——协议支持。sing-box 覆盖了 VMess、VLESS、Trojan、Shadowsocks、Hysteria2、TUIC、ShadowTLS、AnyTLS、Snell、WireGuard 等，入站出站都支持。一些 Clash 跟进较慢的新协议，sing-box 往往更早支持。这也是很多开发者说它「更现代」的原因。

三、为什么它越来越常见

你之所以最近老看到它，是因为很多新客户端开始把 sing-box 当底层引擎：

  • SagerNet 团队自己的客户端系列
  • NekoBox、Clash Verge Rev 的新版本、部分 Android/iOS 客户端，都提供了「sing-box 内核」或「sing-box 核心」选项
  • 软路由（OpenWrt）上，sing-box 常被用来替代/补充 Clash 做更精细的路由

也就是说，你可能已经在用 sing-box 而不自知——你装的某个客户端的「新内核」或「v2 内核」，底子里可能就是它。

四、普通用户该怎么选

这是最实际的问题。给个明确的判断：

如果你现在用 Clash 系客户端（Clash Verge、CMFA 等）很顺手，机场订阅、规则分流、TUN 都正常——没必要为了换而换。

sing-box 更适合这几类人：

  1. 想用 Clash 不支持或跟进慢的新协议（比如某些新出的抗封锁协议）
  2. 在软路由 / 服务器上做精细路由，想要更轻、更可控的纯内核
  3. 折腾、测试新内核的进阶玩家

对绝大多数”只是想上网”的新手，继续 Clash 完全够用。sing-box 是给你”装备升级”用的，不是”入门必备”。

五、如果想用 sing-box 试试

两条路，按你的情况选：

  • 普通用户 → 用内置 sing-box 内核的客户端。直接装支持 sing-box 内核的 GUI 客户端，导入机场订阅，剩下的它帮你配好，基本不用碰配置文件。可选的客户端里，SagerNet（官方团队出品）、NekoBox、以及新版支持切换内核的 Clash Verge Rev 都行；具体挑哪个，和「选 Clash 客户端」逻辑一样——看界面顺不顺手、更新活跃不活跃。
  • 软路由 / 服务器玩家 → 自己写 JSON 配置。直接跑官方内核，写 inbounds（入站）/ outbounds（出站）/ route（路由）/ dns（解析）四块 JSON。这条路适合已经在折腾软路由、路由器或 VPS 的人，新手不建议硬啃 JSON。

一句话：**先搞清楚自己是”想用”还是”想折腾”**——前者装个客户端完事，后者才需要碰内核配置。

六、常见问题

sing-box 是什么？

sing-box 是一个开源的通用代理平台，由 nekohasekai 于 2022 年发起。它不是带界面的客户端，而是一个代理内核，负责处理各种代理协议的入站出站、路由分流、DNS、TUN 等底层能力。

sing-box 和 Clash / Mihomo 有什么区别？

两者都是代理内核，但定位不同。Clash/Mihomo 用 YAML 配置，把内核和规则分流、策略组绑在一起；sing-box 用 JSON 配置，定位更纯粹的通用代理核心，协议支持更广、新协议跟进更快。简单说 Clash 是全家桶，sing-box 是更纯更现代的内核。

sing-box 支持哪些协议？

几乎覆盖主流代理协议：VMess、VLESS、Trojan、Shadowsocks、Hysteria2、TUIC、ShadowTLS、AnyTLS、Snell、WireGuard、SOCKS/HTTP 等，入站出站都支持。

sing-box 支持哪些平台？

官方支持 Windows、macOS、Linux、Android、iOS、OpenWrt 路由器等。多数用户不直接跑内核，而是用内置 sing-box 内核的 GUI 客户端。

我该从 Clash 换到 sing-box 吗？

不一定。用 Clash 顺手、没遇到瓶颈就不用换。sing-box 更适合想用新协议、软路由精细路由、或折腾新内核的进阶玩家。新手继续 Clash 完全够用。

光分清内核还不够，关键还是选对客户端、配好规则分流。客户端怎么选见 Clash 怎么办客户端选哪个；规则分流、订阅这些前置概念，集中在 Clash 教程总览页，一次看全。
