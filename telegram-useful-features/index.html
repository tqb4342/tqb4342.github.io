Telegram 实用功能合集：9 个隐藏技巧

这篇默认你已经会用 Telegram 了。还没入门的，从 Telegram 完全指南 开始，下载、汉化、加搜索机器人，一步步来。

用 Telegram（TG）有一段时间了，发现它比别的聊天软件多了不少好用的小功能。下面是我常用的几个，附操作图。

1. Schedule message 定时消息

比如晚上定个时第二天早上发消息叫醒某人.

定时消息

2.Create poll投票:

有时询问意见没人要参与讨论就直接做个poll出来让大家投票决定,又可以设计为匿名,大家也勇于投票。
Edit功能: 如果发现打错字或要做修改可以就在原信息里edit,不需要再从新打过,也可以避免造成混乱。

群组发起投票

3.Auto delete msg：

嫌群里消息太多了可以set auto clear history，选择每24小时，一个星期或一个月。

自动删除群消息

4.Saved message：

群组太多，不同群里都有些重要的msg，所以我把这些msg forward去我自己的saved message里，方便我找回该msg而不需要去该群scroll上下找。

保存消息

5.删除信息:

这个功能其它聊天工具虽然也有可是删除了对方还是会看到我撤回了信息,telegram就不会,可以趁对方没看到时删除而不留下任何痕迹,就算对方看到了你也可以删除不留下痕迹,还可以赖对方看错了

双向删除消息

6.Pin功能:

就算你mute了该群,可是当你pin msg出现时还是可以选择notify all members,所以组员mute了该群也没用

pin

7.Self-destruct timer:

自动销毁信息或图片,最短1秒,最长1分钟,对方在看了你的图片后就会在双方手机里自动销毁该图片,过后怎样都搜不到。不像手动删除的,手动删除的对方的手机里还是可以找到你的图片,可是self-destruct是找不到的。另外self-destruct图片要点进去才能看到和开始计时，没点进去前是朦朦的。(图6)

消息销毁时间

8.Secret-chat

在这里所有msg都不能被forward不能被screenshoot，也能设计为self-destruct timer。

加密会话

9.群发消息：

有时候需要给别人群发消息，这时候我会用一个插件来帮助我
