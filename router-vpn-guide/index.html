路由器翻墙教程（2026）：OpenWrt+Clash 软路由科学上网

阅读量 loading
科学上网 Clash 路由器翻墙 软路由 OpenWrt OpenClash 旁路由

📚 本文是 科学上网完全指南（2026最新版） 系列教程之一，专注「路由器 / 软路由」这个环节：让全家所有设备不装任何客户端，连上 Wi-Fi 就能科学上网。

30 秒速答

  • 路由器翻墙是什么：把代理软件装进路由器，全家设备（手机、电脑、电视盒子、游戏机、智能家居）连上它就自动翻墙，一台设备都不用装客户端。
  • 怎么实现：刷 OpenWrt 固件 + 装 OpenClash 插件 + 导入机场订阅，三步。原厂 TP-Link、小米、华为路由器都刷不了或难刷，最省事是买台 N100 软路由小主机。
  • 订阅哪来：路由器只负责跑节点，节点来自机场订阅。本站自用一枝红杏（Trojan 协议，99 元/年起，官方支持 OpenWrt）。

一、路由器翻墙：一次配置，全家生效

平时在电脑、手机上翻墙，每台设备都要装一个客户端。设备一多就烦：电视盒子装不了客户端、Switch 没地方装 App、家里老人的手机你总不能远程帮他配代理。

路由器翻墙解决的就是这个：把代理软件直接装进路由器。所有连上这台路由器的设备，流量在路由器这一层就被分流——访问国内网站走宽带直连，访问被墙的网站自动走代理。对设备来说完全透明，不需要任何设置。

它特别适合这几类人：

  • 家里设备多：手机 + 电脑 + 平板 + 电视盒子 + 游戏机，一台台装客户端不现实
  • 有装不了客户端的设备：Apple TV、Switch、PS5、Chromecast、智能家居设备
  • 想让全家（包括不懂技术的家人）无感翻墙的人
  • 已有机场订阅，想榨干「同时在线设备数」上限的重度用户

反过来说，如果你只有一台手机一台笔记本，设备上装个客户端就够了，没必要上路由器方案——怎么选客户端看 Clash 完全教程。

二、先说清路线：为什么不是「路由器装 VPN」

网上很多「路由器翻墙」教程教的是给路由器装 ExpressVPN 这类 VPN 服务——这条路在中国大陆基本走不通：这类 VPN 的服务器本身就长期被墙，路由器上连它的服务器都连不上，翻墙无从谈起。

还有些教程教你买「出厂自带翻墙功能的路由器」——电商平台上这类商品要么是刷了老版本固件的杂牌货（协议早已被识别，用几天就全红），要么干脆是骗局。2026 年还能长期稳定跑通的家用方案，主流路线只有一条：

OpenWrt（开源路由器固件）+ OpenClash（Clash 系代理插件）+ 机场订阅

这条路线的本质，是把电脑上的 Clash 客户端搬进路由器：吃同一份机场订阅（Trojan/VLESS/Reality 等抗封锁协议）、用同一套规则分流（国内直连、国外代理）、同样支持节点切换和测速。你在 Clash 教程里学的概念，在路由器上一个不少。

三、硬件怎么选：三条路与性能对照

方案 成本 适合谁 门槛
旧路由器刷 OpenWrt 0 元（利用旧设备） 手上有老路由器、爱折腾 高：要查型号兼容、有变砖风险
专用软路由小主机（N100） 500-1000 元 想一步到位、长期用 低：买来装好系统就能用
旁路由（任意 OpenWrt 设备） 取决于设备 不想动家里现有网络 中：改一两处网络设置

路线一：旧路由器刷机（零成本，折腾向）

不是所有路由器都能刷。第一步先去 OpenWrt 官网的硬件兼容列表（Table of Hardware）搜自己的型号，查三样东西：有没有对应固件、稳定性评级、FLASH 和内存容量（低于 16MB FLASH / 128MB 内存的型号跑 OpenClash 很勉强）。

刷机流程大致是：下载对应型号的固件 → 进入原厂系统的刷机界面（或 telnet/SSH）刷入 OpenWrt → 装插件。听起来简单，但每个型号的操作细节都不同，中途断电就是变砖，救砖要拆机接 TTL 线。动手前务必照着你这个型号的专属教程走，不要凭感觉。

另一个现实问题：中低端路由器的 CPU 性能弱，跑代理加密解密可能只有几十兆速度。宽带是 500 兆以上的，刷机路线基本喂不饱。

路线二：软路由小主机（推荐，一步到位）

N100 小主机是当下的主流选择，几百块钱，性能足够跑满几百兆到千兆宽带。选购看四点：

  • CPU：Intel N100 或 N305，支持 AES-NI 硬件加密加速，代理速度和 CPU 占用差距巨大
  • 网卡：2.5G 双网口起步（一个接光猫、一个接家里路由器或交换机）
  • 散热：无风扇被动散热，24 小时挂机不吵、不易积灰
  • 内存：8GB 起步，跑 OpenWrt 绰绰有余

到手一般预装了 OpenWrt 或 iStoreOS（基于 OpenWrt 的易用发行版，带图形化应用商店，装插件从命令行变成点鼠标），新手直接用 iStoreOS 就好，两者插件生态完全通用。

路线三：旁路由（不是买什么，是怎么接）

旁路由不是独立的硬件类别，而是「怎么接入家里网络」的方案——任何刷好 OpenWrt 的设备都能当旁路由。它的价值是不动现有网络结构，家里主路由、其他设备完全不受影响，最适合作为入门起点，第七节详细讲接法。

宽带和硬件怎么匹配

  • 100-300 兆宽带：老路由器刷机勉强够用，N100 轻松
  • 500 兆-1 千兆：直接上 N100 级别，老路由器刷机跑不满
  • 家里同时翻墙设备超过 10 台：N100 起步，注意机场订阅的连接数限制

四、OpenWrt + OpenClash 配置流程

以软路由小主机（预装 OpenWrt / iStoreOS）为例，从零到全家翻墙四步：

第一步：准备工作。软路由接显示器键盘（或直接用网线连电脑进管理后台），默认后台一般是 192.168.1.1，按系统提示把上网方式配好（宽带拨号或上级路由 DHCP），确认本身能正常上网。

第二步：装 OpenClash。iStoreOS 用户直接在应用商店搜 OpenClash 一键安装。原版 OpenWrt 走「系统 → 软件包」：先点「刷新列表」，再搜索 luci-app-openclash 安装。如果刷新列表失败（固件源被墙或 DNS 问题），去 OpenClash 的 GitHub Releases 页下载 .ipk 离线包，在软件包页面上传安装。装完在「服务」菜单里就能看到 OpenClash 入口。

第三步：导入机场订阅。先得有一份订阅——没有的看下一节的订阅获取。拿到订阅链接后，在 OpenClash 的「配置订阅」里粘贴链接、更新并启用配置。两个细节：一是订阅更新建议设成自动（每天凌晨拉一次，节点失效能自动跟上）；二是首次启动会让选内核，选 mihomo（Clash Meta）内核，和电脑端同一套东西，站内 Clash 教程的规则语法都能直接复用。

第四步：启动并验证。启动 OpenClash，等面板状态变绿，把手机连上这台路由器的 Wi-Fi，打开 Google 能通、打开百度也正常，就成了。节点切换、延迟测速、规则覆盖都在 OpenClash 面板（「控制面板」标签）里操作，界面和电脑端 Clash 面板一致。

五、订阅从哪来：机场是前提

路由器方案有个前提经常被教程一笔带过：OpenClash 只是工具，节点来自机场订阅。没有订阅，路由器刷得再好也翻不了墙。

选机场给软路由用，重点看三条：

  • 协议抗封锁：优先 Trojan、VLESS+Reality 这类难被识别的协议，软路由是 24 小时挂机的，协议稳定性比什么都重要
  • 官方支持 OpenWrt：有无软路由使用说明、是否限制设备数（路由器方案下全部设备共享一个连接，机场按连接数计费的话很吃亏）
  • 支付和售后：支持支付宝年付、有工单系统

本站长期自用的是一枝红杏：Trojan 协议（流量伪装成正常 HTTPS），99 元/年的入门版每月 100G 流量，官方明确支持 OpenWrt 系统，路由器翻墙场景完全够用。想横向对比其他机场的，看 Clash 机场选择指南。

六、两个关键设置：规则模式和 DNS 防泄漏

路由器是全家的网关，配置错了全家断网。两个设置务必确认：

用规则模式，不要全局代理。全局模式会让所有流量都绕道海外节点——看国内视频、玩国服游戏全变慢，还白烧机场流量。OpenClash 默认的规则模式就是「国内直连、国外代理」，保持默认即可；想自定义规则，思路和电脑端 Clash 一致（GEOIP,CN,DIRECT 是底线规则）。

DNS 别泄漏。在 OpenClash 里开启「本地 DNS 劫持」，让设备的 DNS 请求也走代理层处理。不开的话会出现两类怪问题：网页能打开但部分 App 提示网络异常（App 检测到国内 DNS 返回的结果不对）、Netflix 这类流媒体判定地区错误。原理展开讲透的是 Clash DNS 专题，路由器端照抄里面的思路即可。

顺手关掉固件的 IPv6。一部分宽带会下发 IPv6 地址，而不少代理插件默认只处理 IPv4 流量——设备可能「聪明地」走 IPv6 直连出去，造成真实地址泄漏。进 OpenWrt 后台把 LAN 口的 IPv6 分配关掉，是软路由圈的常规操作。

配好之后如果出现「节点全红连不上」「部分 App 不走代理」，按 Clash 排障指南逐项排查——软路由上的问题九成和客户端是同一类，剩下的一成多半是时间不同步（系统时间差几分钟，Trojan 的 TLS 证书校验就会失败），在后台开启 NTP 时间同步即可。

七、旁路由：不动主路由的稳妥接法

直接把软路由当主路由，一旦 OpenClash 抽风，全家断网，家人第一个喊你。更稳妥的接法是旁路由：

  1. 软路由（刷好 OpenWrt + OpenClash）网线接在主路由的 LAN 口，软路由这端也用 LAN 口（不用 WAN 口）
  2. 软路由后台：关掉自身的 DHCP 服务，IP 设成和主路由同网段的固定地址（比如主路由是 192.168.1.1，软路由设 192.168.1.2）
  3. 需要翻墙的设备：在 Wi-Fi 设置里把「网关/路由器」手动改成 192.168.1.2——只有这些设备走代理，其他设备照旧走主路由

好处是隔离故障：软路由挂了，把设备网关改回自动就恢复；家人不懂翻墙的设备完全不受影响。

用顺了想全家无感翻墙（设备一个都不用手动改）时，把主路由的 DHCP 下发的网关和 DNS 都指向软路由地址即可——这样所有新接入的设备自动走软路由，全家方案和旁路由方案之间可以随时切换，进退都方便。

八、常见翻车点速查

症状 多半是 处理
节点测速全红 订阅过期、机场服务器被墙 先在电脑端 Clash 测同一份订阅定位问题；订阅失效找机场续费或换
能上 Google，App 提示网络异常 DNS 泄漏 开「本地 DNS 劫持」，参考 Clash DNS 专题
国外网站时通时断 节点负载高或协议被识别 换协议（Trojan/Reality），或换机场
看国内视频变慢 误开了全局模式 切回规则模式，确认 GEOIP,CN,DIRECT 在规则里
Trojan 节点全部握手失败 软路由系统时间不对 后台开 NTP 同步，重启 OpenClash
全家突然断网（软路由当主路由时） OpenClash 进程挂了 进后台重启 OpenClash；长期方案是改旁路由接法

九、成本总账：全套下来要花多少钱

项目 花费 说明
软路由小主机（N100） 500-1000 元 一次性投入，可长期用
机场订阅 99 元/年起 一枝红杏入门版；流量大户选更高档位
电费 约 30-60 元/年 N100 整机 6-15 瓦
家里现有主路由 0 元 旁路由方案完全不动它

对比一下：手机上装客户端是免费，但电视盒子、游戏机这些设备永远装不了；而路由器方案一次配好，全家所有设备、包括未来新买的设备，连上 Wi-Fi 就生效。设备多的家庭，这是使用体验的天花板。

十、通了之后：全家设备能干什么

路由器翻墙最大的红利，是那些平时没法翻墙的设备突然全解锁了：

  • 电视盒子 / Apple TV：YouTube、Netflix 大屏看。奈飞账号不用单开，环球巴士合租一个月十几块；只想要大屏看剧的，爆米花五平台合租一次覆盖 Netflix、Disney+、HBO Max
  • 游戏机：Switch / PS5 直连外服商店和联机，不用再折腾加速器；游戏本体价格外服时常比国服便宜，回本速度比想象中快
  • 手机：Telegram、ChatGPT 随手就用，而且不用每台手机挂客户端——Telegram 怎么注册看电报下载注册教程（iOS 用户需要先备一个美区 Apple ID，流程看苹果 ID 购买教程），AI 会员怎么买便宜看 AI 大模型充值教程
  • 智能家居：接 Google、Alexa 生态的设备恢复正常联动
  • 访客设备：朋友来家连 Wi-Fi 自动翻墙，不用帮人装 App

总结：路由器翻墙 = OpenWrt + OpenClash + 机场订阅，一次配置全家生效。设备少就别折腾（客户端方案更省心），设备多、有电视盒子游戏机的，这是终局方案。上手建议从旁路由接法开始，翻车不影响全家；硬件一步到位选 N100 小主机，旧路由器刷机留给爱折腾的人。订阅选抗封锁协议的机场（本站自用一枝红杏），规则模式保持国内直连、DNS 劫持打开、IPv6 关掉，就能长期稳定跑下去。
