科学上网客户端大全（2026）：全平台翻墙软件下载清单

这两年科学上网的协议一年比一年多，客户端跟着一轮换血——去年还是主力的一些软件，今年已经停更甚至删库跑路。网上搜「翻墙客户端下载」，出来的清单大半是 2023 年的老黄历，还在推荐已经死掉的软件。这篇把 2026 年还在正常维护的全平台客户端汇总到一页：每个平台直接告诉你装哪个、去哪下、装完看哪篇教程。可以把本页加为书签，客户端换血时这里会同步更新。

30 秒速答

  • 每平台直接装这个：Windows / macOS 选 Clash Verge Rev，安卓选 ClashMeta for Android，iOS 选 Spectre 或 Shadowrocket，软路由选 OpenClash——理由和下载入口见下文分平台清单
  • 全免费吗：电脑和安卓客户端全免费开源；iOS 是例外，付费加外区 Apple ID，前置流程看 iPhone 科学上网教程
  • 下载只认一个地方：各软件的 GitHub 官方仓库 Releases 页面，别碰搜索引擎广告位的「官网」
  • 客户端只是壳，节点才是核心：装哪个软件影响顺手程度，节点质量决定快不快稳不稳——这层关系展开看梯子软件怎么选
  • 新手最常见翻车：装了免费客户端塞公共免费节点，得出「翻墙不好用」的结论——不是软件不行，是节点不行

一、先把两层关系摆正

看清单之前先花 30 秒搞清一件事，能省掉后面一大半折腾。

客户端是壳：装在电脑手机上的软件，负责导入节点、开关代理、跑分流规则。这一层全平台开源免费，选错了换一个就行，没有任何成本。

节点是核心：机场给你的那条订阅链接，里面才是真正连境外的服务器。快不快、稳不稳、ChatGPT 掉不掉线，七成由这层决定。这层要花钱，怎么选方案看科学上网方案怎么选。

所以这篇清单解决的是「壳」的问题——每个平台哪个壳最顺手、去哪下。壳选对了，剩下的体验差距全在订阅上。

二、Windows 客户端

Clash Verge Rev（主力推荐）

Windows 上的第一选择。mihomo 内核，订阅导入、节点测速、规则分流一应俱全，界面现代，更新勤快，新手到老手都用它不亏。从下载安装到导入订阅跑通的完整流程，看 Clash Verge 教程。

下载：GitHub Releases

两个新手会慌一下的正常现象：安装包没有微软签名，Windows 装完可能弹「已保护你的电脑」，点「更多信息 → 仍要运行」即可；首次启动连不上网，先检查界面左下角的系统代理开关有没有打开，不是软件坏了。完整排障在 Clash Verge 教程。

Mihomo Party（活跃维护）

近两年冒出来的新派客户端，mihomo 内核，界面是几个 Windows 客户端里最现代的。Clash Verge Rev 用腻了换它换换口味，订阅和配置习惯无缝平移。

下载：GitHub Releases

v2rayN（活跃维护）

Windows 老牌全能选手，v2ray 系协议支持最全，功能多到界面略显复杂。主力协议走 Clash 系的用户用不上它，但很多机场的排障文档默认写它，手里备一个不亏。

下载：GitHub Releases

Hiddify（活跃维护）

全平台统一体验的客户端，Windows / macOS / Android / iOS 一个全家桶。多设备党不想每个平台学一套软件，选它。下载：GitHub Releases

Clash for Windows（已停更）

曾经的 Windows 霸主，2023 年底停更删库。现在没有任何新装理由——还在用它的老用户，停更原因和迁移指南看这篇，尽快换到 Clash Verge Rev。

三、macOS 客户端

Clash Verge Rev（主力推荐）

Windows 那套原封不动搬到 Mac，Intel 和 Apple Silicon 都有安装包。会用一个平台等于会了所有平台，这是跨平台客户端的价值。教程同样看 Clash Verge 教程。

下载：GitHub Releases

Mihomo Party（活跃维护）

Mac 原生体验做得最好的一个，深色模式、菜单栏控制都到位，Mac 用户可以直接拿它当主力。订阅导入与节点配置的完整流程看 Clash Party 教程。

下载：GitHub Releases

Surge（付费）

Mac 上的专业级选择，稳定性和规则能力是天花板级别，价格也是。重度用户和愿意为工具付费的人用得出它的好。下载：官网 nssurge.com

四、Android 客户端

ClashMeta for Android（主力推荐）

安卓 Clash 系的正统续作。mihomo 内核，新协议跟得上，机场订阅直接导入，配置流程看安卓科学上网教程。

一个高频踩坑单独提醒：原版 Clash for Android 已停更在 2.5.12，商店和搜索引擎里搜「Clash for Android」装到的是停更老版。认准 ClashMeta 这个名字。

下载：GitHub Releases

v2rayNG（活跃维护）

安卓另一大主流，v2ray 系协议通吃，界面简单直接，很多机场的安卓用户手册默认写它。

下载：GitHub Releases

Hiddify（活跃维护）

全平台家族的安卓成员，其他设备已经在用 Hiddify 的话，安卓装它保持体验统一。下载：GitHub Releases

Surfboard（轻量之选）

安卓轻量级选手，兼容 Surge 配置。机器性能差、或者只想要一个「能连上就行」的开关，选它。

下载：GitHub Releases

五、iOS 客户端

iOS 是唯一绕不开钱的平台：App Store 里的翻墙客户端基本都收费，而且大多只在美区等外区商店上架。所以先解决外区 Apple ID，再谈装哪个，完整流程看 iPhone 科学上网教程。

Spectre（付费）

小火箭 Shadowrocket 同一作者的新作品，iOS 新设备目前的首选，本站 iPhone 教程以它为主线。购买和配置全流程看这里。

Shadowrocket（付费，经典）

iOS 最经典的一个，几美元买断，生态成熟：几乎每家机场的 iOS 文档都默认它。需要美区账号，美区 Apple ID 购买与防封指南有完整流程。

Stash（付费）

iOS 上的 Clash 系，订阅和规则玩法跟桌面端一脉相承。安卓、桌面在用 Clash、想把配置习惯带到 iPhone 的人选它。

sing-box（付费）

sing-box 内核的官方 iOS 端，新协议支持最快，配置偏极客向。跟 Clash 的区别想搞明白，看 sing-box 和 Clash 对比。

六、软路由与梅林

想让全家设备无感翻墙，就把客户端装进路由器：代价是折腾成本，收益是手机电视冰箱都不用单独装软件。方向入门看路由器翻墙教程。

OpenClash / Nikki（OpenWrt）

OpenWrt 软路由的两大主流方案。OpenClash 老牌、资料多；Nikki 新派、内核更新快，二选一即可。OpenClash 仓库：GitHub

Merlin Clash / fancyss（华硕梅林）

华硕路由刷梅林固件后的两大插件，华硕玩家基本都在这两者之间选。fancyss 偏傻瓜化，Merlin Clash 玩法上限高。fancyss 仓库：GitHub

七、下载避坑：三条铁律

清单看完了，下载这一步还有三个坑，踩中一个就前功尽弃。更完整的辨假方法在猫咪专文，这里给最短版本：

  • 只认 GitHub Releases：本页所有下载链接都指向官方仓库的发布页。搜出来名字一样、域名不一样的一律不点

上图就是典型的二次打包下载站：文件名跟官方一模一样，旁边混着一个「-Chinese」后缀的中文版安装包——官方从没发过中文特别版，多出来的东西就是别人加进去的。

  • 广告位里的「官网」是假的：搜索引擎广告位里的「Clash 官网」「v2ray 官网」九成九是钓鱼，专收着急的新手
  • 收费的「Clash 系客户端」是山寨：Clash 系全部开源免费，收软件费的基本是二次打包加料版

八、客户端不等于节点：最后一步

软件装好了，最后一件事决定你到底好不好用：节点从哪来。免费公共节点人数挤爆、晚高峰卡到打不开页面、随时失联，属于能凑合但没法日常用的水平——大量「翻墙不好用」的差评，锅都在节点不在软件。

正经用，两条路：

  • 省事派：直接买机场订阅，节点、线路、维护全包，客户端导入一条订阅链接就完事。一枝红杏 是本站主推的机场，7 年老牌、有试用额度、对 ChatGPT 等 AI 服务友好，实测与套餐价格看这篇

买完机场拿到的就是上图这样一个页面：Clash、Surge、Shadowrocket 各有各的订阅按钮，点开复制链接，粘进对应客户端就跑起来了——一条订阅喂全平台，这就是「客户端只是壳」的意思。

  • 折腾派：自己租 VPS 搭节点，自由度最高，成本和心智负担也最高，适合当学习项目，方案对比看科学上网方案怎么选

装完客户端、导入订阅之后，分流规则、TUN 模式这些进阶玩法，在 Clash 完全教程里接着学。

FAQ 常见问题

科学上网客户端哪个好？

按平台直接抄答案：Windows 和 macOS 选 Clash Verge Rev，安卓选 ClashMeta for Android 或 v2rayNG，iOS 选 Spectre 或 Shadowrocket，软路由选 OpenClash 或 Nikki。这些全是 GitHub 开源项目，免费、仍在维护、新协议跟得上。

这些客户端都是免费的吗？

电脑和安卓的主流客户端全部免费开源。iOS 是例外：App Store 里的翻墙客户端基本都收费，而且大多只在美区等外区商店上架，先解决外区 Apple ID 再谈装哪个。

Clash for Windows 还能用吗？

不推荐。它是曾经装机量最大的 Windows 客户端，2023 年底作者删库停更，之后再没安全更新。还在用的建议尽快迁移到 Clash Verge Rev，迁移方法在站内 Clash for Windows 停更专文里。

客户端和机场订阅是什么关系？

客户端是装在设备上的软件，负责把订阅里的节点接进来；机场订阅是花钱买的那条链接，里面才是真正干活的境外服务器。客户端免费、订阅收费，一条订阅可以导入全平台所有客户端。

下载翻墙客户端怎么避免山寨？

只认 GitHub 官方仓库的 Releases 页面。搜索引擎广告位里的「Clash 官网」九成九是假的，第三方下载站的二次打包版本也不碰。本页所有下载链接都指向官方仓库。

免费客户端是不是等于免费上网？

不是。客户端免费只解决了软件这一层，节点才是另一回事：免费公共节点晚高峰拥挤、随时失联，日常稳定使用需要机场订阅，月付十几元起。想省钱先试机场的试用额度，别长期挂公共免费节点。
