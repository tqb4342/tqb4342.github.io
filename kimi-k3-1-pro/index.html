Kimi K3.1 Pro 实测（2026）：草图变 3D 网页，全球第四

大模型 Kimi AI 工具

昨天（2026-10-24）Kimi 发了 K3.1 Pro，X 和 reddit 直接刷屏——知名评测机构 Artificial Analysis 给它打了 55 分，全球智能指数第四，比前代暴涨 11 分；Terminal-Bench 4.0 上从 13%飙到 65.7%，距离 Opus 5.5 不到 1 个百分点。

国产模型前十几乎没有存在感的沉默期，被这一发打破了。下面按分数、实测、价格的顺序挨个过，看完你自己判断要不要换。

30 秒速答

  • 全球智能指数第 4（55 分），前代 K3 是 44 分
  • Terminal-Bench 4.0 拿 65.7 分，终端 Agent 能力第一梯队，距 Opus 5.5 不到 1 个百分点
  • 3 万亿参数、100 万上下文，价格只有 GPT-6 Astra 的五分之一，比 K3 还便宜三分之一
  • 招牌新技能：文字/草图 → Blender 建模 → 网页一条龙，实测 40 分钟交活
  • 免费额度就能用，kimi.com 和 Kimi App 已同步上线，3D Make 云端功能免费
  • 有高速版 K3.1 Pro Highspeed，输出快 3 倍

分数先看懂：三个数字的含义

跑分是门票，得知道每张门票代表什么。

全球智能指数第 4 名。Artificial Analysis 的综合智能指数，K3.1 Pro 拿 55 分排第四，前面是 GPT-6 Astra、Opus 5.5、Fable 5.1 这些海外旗舰——reddit 上讨论最凶的就是它超越了 Fable 5.1 这件事。更狠的是评测机构的另一个判断：权重一旦发布，K3.1 Pro 将登顶开放权重模型榜首，开源与顶级闭源的差距从 12 分缩到 3 分。官方已确认完整权重两周内放出，到时候榜单还得重洗一次。

上图就是 Artificial Analysis 的智能指数榜，K3.1 Pro 的 55 分卡在第四位，身后是一排海外旗舰——这个位置此前从没出现过国产模型的名字。

Terminal-Bench 4.0：从 13 分飙到 65.7 分。这个测试考察 Agent 在真实终端里独立干活——装环境、跑命令、排错，全是程序员日常。从上一代 13 分到 65.7 分的跳变，意味着「让 AI 自己在命令行里干活」这件事，它已经摸到 Opus 的门框了。

成本是 Astra 的五分之一。同样的钱它干得最多，同样的活它花得最少——Artificial Analysis 判断它在三种思考强度下都落在「性能与单任务成本」的帕累托前沿上。翻译成人话：性价比怪物。

想系统了解 Kimi 系列怎么注册上手、免费额度怎么用，看 Kimi K3 教程，步骤对 K3.1 Pro 完全通用。

实测一：文字 → Blender → 网页，一条龙

这是 K3.1 Pro 主打的新能力：给它一段文字、一张手绘草图或参考图，它推断形状、比例和空间关系，自己写 Blender 脚本建模，再接上 Three.js 出一个能交互的网页。全程不碰 MCP 连接器、不用外部模型库。

输入是一张手绘三视图，纸面上标好了全部尺寸：

实测流程是这样的：这张草图（标注翼展 8.0、总长 6.2、总高 2.4）扔进去，40 分钟后交出来的东西包括：608 行 Blender 脚本、可编辑的 .blend 文件、1.7 MB 的 GLB、一个双击就能打开的网页。建出来的模型实测尺寸 8.000、6.199、2.400，和草图标注差 1 毫米。

过程细节比结果更能说明问题：

  • 动手前先试探 Blender 5.2 的新接口，确认了才写正式脚本
  • 验收标准直接写成断言：旋翼直径差 1 毫米就不许导出
  • 渲染完自己对照草图改了一轮
  • 网页做完自己开浏览器截了两张图，确认没问题才交差
  • 六项待办清单，自己一项项划掉

终端里的实拍长这样——写网页、起本地服务器、待办逐项划掉，全程没有人工介入：

机身是样条插出来的流线体，座舱玻璃是吸附在机身上的曲面，桨叶带扭转，四个旋翼的倾转层级从 Blender 一路保留到浏览器里——网页上拉滑块，旋翼真的绕支臂往前倒 90°。写到一半时 100 万上下文才用了 6%。

最终交付的网页是个可交互的 3D 配置器：换机身配色、拉倾转滑块，尺寸数据直接标在旁边：

40 分钟是这张草图的上限，不是它的上限。

云端版：3D Make，本地不装 Blender 也能干

上面那条链路听上去还是程序员姿势？kimi.com 和 Kimi App 上线的 3D Make 功能把它变成了普通人姿势：

把草图和资料直接丢进 Kimi，说一句「参考这些资料，把它的 3D 模型做出来」，它就在云端开工——同样 40 分钟左右，改脚本、跑重建、发现桨叶转起来不对称就改成半整数转速、CSS 动画暂停不一致就修，最后自己开浏览器点一遍，报「无脚本错误或资源缺失」才交版本。

成品能在线预览、一键发布成网页，GLB 下载下来可以直接去 3D 打印，还能导出视频或实况照片发社交平台。不满意在对话里说，它接着改。

界面就是左边聊、右边转：对话里下指令，右侧窗口实时转模型、换配色、拉倾转滑块，改完直接在同一个窗口里验收。

以前这是建模师、前端、运营三个人的活，现在是一个输入框。

网友的实测也炸出一批：4.92 美元在一款绘画应用里画出肖像；虚幻引擎里建了一座云端宫殿成本不到 10 美元；还有那个审美被夸上天的鹈鹕骑自行车 demo。

实测二：金融建模，端到端交 Excel

AI 碰金融翻车是老梗了——写摘要凑合，一遇到跨表公式和估值模型就胡言乱语。K3.1 Pro 这次直接把这块硬骨头啃了：

  • OfficeQA Pro v2（真实金融文档的复杂财务分析）拿下 64.4 分，当前最优
  • Frontier Finance（覆盖标的筛选到盈利分析的整条投资工作流）位列第二

实测里它交出的是一份英伟达财务模型：不是填表，是带公式联动的完整 Excel——经营驱动因子可随情景调整，敏感性分析直接呈现对估值的影响，每项假设都有数据支撑。像极了老练的分析师，或者说，一个真正懂财务逻辑的全栈金融民工。

高速版：K3.1 Pro Highspeed

同步推出的还有 K3.1 Pro Highspeed：智商基本不减，输出速度提升约 3 倍。日常问答、轻量任务这类对响应速度敏感的场景用高速版，硬核推理和长任务用标准版，各干各的。

该不该用：和海外旗舰怎么选

结论分两半。

能力上：3D 建模、终端 Agent、金融建模这些任务已经能和 GPT-6 Astra 正面交锋，部分高难度推理维度离最强闭源模型仍有差距——它不是全能冠军，是「前沿模型里最理性的那个选择」。

现实上：这才是国产模型真正的护城河。K3.1 Pro 国内直连、免费额度就能用；Astra 和 Opus 得先有稳定的出海线路才能摸到。网络没解决的用户，K3.1 Pro 就是现实可得的最强档。想让家里网络先达标的，从 Clash 完全教程 起步；想两边都体验做对比的，AI 大模型怎么买便宜 里有不用外币卡的开法。

编程党还有一层选择：K3 系在 AI 编程工具怎么选 的格局里属于「国产直连免费路线」的主力——Kimi Code 的 CLI 和 VS Code 插件对标 Claude Code，K3.1 Pro 的 Agent 能力涨上来之后，这条路线的含金量又高了一截。

常见问题

Kimi K3.1 Pro 免费吗？

免费。K3.1 Pro 已在 kimi.com 网页版和 Kimi App 同步上线，新模型在免费额度里就能用，3D Make 功能也是免费开放，不需要额外付费开会员。

K3.1 Pro 和 K3 该用哪个？

直接用 K3.1 Pro。它是基于 K3 做的后训练升级，代码、Agent、知识类基准全面超过 K3，价格反而便宜三分之一，官网入口也是同一个，没有理由留在旧版。K3 的注册和上手流程看 Kimi K3 教程，步骤完全通用。

3D 建模真的不用本地装 Blender？

不用。kimi.com 的 3D Make 功能在云端跑，丢一张草图加一句指令，它自己在云端写脚本、建模、渲染、出网页，GLB 文件下载下来可以直接去 3D 打印。想本地精修的再下载 .blend 文件用 Blender 编辑。

K3.1 Pro 能替代 GPT-6 Astra 吗？

分场景。3D 建模和终端 Agent 这类任务已经能正面交锋，价格还便宜 80%；但在部分高难度推理维度，离最强闭源模型仍有差距。国内直连能稳定用是它最大的优势——Astra 需要出海线路，网络没解决的用户，K3.1 Pro 是现实可得的最强档之一。

K3.1 Pro Highspeed 是什么？

官方同步推出的高速版模型，智商基本不减，输出速度提升约 3 倍，适合日常对话、轻量任务这类对响应速度敏感、对推理深度要求不高的场景。

Terminal-Bench 65.7 分是什么水平？

Terminal-Bench 4.0 考察 Agent 在真实终端里独立干活的能力，K3.1 Pro 从上一代的 13 分冲到 65.7，距离 Opus 5.5 不到 1 个百分点，属于第一梯队。简单说，让它自己在命令行里装环境、跑脚本、修 bug，已经接近海外最强水平。

总结

K3.1 Pro 这次是真把东西端上来了：全球第四的分数、终端 Agent 第一梯队、3D 建模一条龙、价格砍到 Astra 五分之一，而且免费额度就能用。国模不是掉队了，是在攒大招。对普通用户就一句话——打开 kimi.com 直接试，一张草图丢进 3D Make，40 分钟后你会回来转发的。编程党把 Kimi Code 的模型切到 K3.1 Pro，等同一件事。
