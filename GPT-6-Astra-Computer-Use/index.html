一、Computer Use 是什么：从「聊天」到「干活」

过去两年你用 ChatGPT 的方式是「聊天」：问一句，答一段，复制粘贴到别的地方自己动手。Agent 类产品进了一步——能联网搜资料、能调 API，但一旦遇到没有 API 的软件（老企业的内部系统、专业设计软件、那个只有你们公司才有的报销网页），它就歇菜了。

Computer Use 换了个思路：不给 API，直接给屏幕。

工作原理就三步：

  1. 看：持续截屏，识别界面上的按钮、输入框、菜单——不靠接口，靠眼睛
  2. 想：理解当前任务进行到哪一步、下一步该点什么
  3. 动：移动鼠标、点击、输入文字——和人操作电脑完全一样

这为什么重要？因为世界上绝大多数软件永远不会有 API。你公司五年前外包开发的 OA 系统、只能网页操作的银行后台、领导指定不许改的报销流程——这些「数字化洼地」以前自动化永远绕不过去，现在 AI 靠「会用界面」直接碾过去了。

三、10 个实战场景

以下场景全部来自 OpenAI 官方演示与发布说明，按「明天上班就能用」的顺序排列。

1. 批量填表单

最朴素也最普遍的场景。老旧系统录入、重复报名表、后台信息维护——给它一份数据源和目标页面，它自己一行行填。误操作率 2.4% 意味着填一百个字段错两个多点，人工抽查的成本远低于自己敲完。

2. 更新 CRM

销售最烦的活：客户资料维护。把聊天记录、邮件线索丢给它，它自己去 CRM 里改字段、补电话、更新跟进状态。这类「规则明确 + 步骤固定 + 量大」的任务，是性价比最高的切入点。

3. 整理日历

跨邮件、跨聊天工具约会议：它自己翻邮件找到双方都有空的时间段，打开日历软件建好日程、写好邀请。发布会演示里它甚至能顺着公司同事的日程习惯做安排。

4. 起草邮件

不是「帮你写一封邮件」那么简单——它自己打开发件界面，基于上下文起草、填好收件人、按你的语气习惯调整措辞。你只需要最后点一下发送。

5. 数据分析出图

把表格丢给它：「按地区汇总上季度销售额，画成柱状图发到周报群里」。它自己开表格软件、写公式、生成图表、导出、发送——一条指令，全程不喊人。

6. 一句话搭网站

发布会演示的 Sites 功能：一句 prompt 直接生成可用的网站，甚至能做小游戏。对做落地页、活动页的运营同学，这比找外包快一百倍。

7. 前端 QA

自己写的页面自己测：Astra 能以真实用户视角点遍所有交互路径，检查按钮反馈、表单校验、边界情况——比写自动化测试脚本省事得多，因为它不需要「写脚本」，直接「用页面」。

8. 设计 PCB 电路板

发布会实拍：Astra 打开 KiCad，自己放元器件、自己布线，把原理图转成可制造的 PCB（来源：OpenAI）

这是全场最炸的演示。KiCad 没有任何 API，Astra 纯靠看屏幕操作专业设计软件——这件事的技术含义远超「办公自动化」：专业工具的门槛正在被 AI 拆掉。

官方演示看着完美，民间实测是什么水平？用 Astra 实际复现这个 KiCad 任务，DRC 报了 12 项违规——翻车全过程和另外三个项目（3D 城市生成器、全栈应用、复刻 Cursor）的实测，见 GPT-6 Astra 写代码实测：Codex 到底强在哪。

9. 3D CAD 几何重构（BenchCAD）

给它几张不同角度的渲染图，它能反推出 3D CAD 代码，几何重合度 **95.9%**，API 成本比上代低 43%。逆向工程、旧图纸数字化，这类以前按人天计费的活，成本曲线直接被改写。

10. 长任务异步跑

Computer Use 配套的机制升级：遇到无关紧要的缺失信息它自己补，只有关键信息缺失才来问你；你不在的时候它先干别的，你回复了它接着做。这意味着「几小时级别的任务」可以真正放手——你去开会，它在家里干活。

四、主动追问还是自动补全？

这是 Astra 在产品层面最值得琢磨的一个设计：它知道什么时候该问，什么时候不该问。

以前的 Agent 两种极端：要么事事都问（烦死），要么全靠猜（错死）。Astra 的策略是按「信息的关键程度」分诊——

  • 缺的是无关细节（比如表单里某个选填备注）：自己合理补全，不吵你
  • 缺的是关键决策（比如「这两个方案删哪个」）：停下来等你，而且等的时候不闲着，先把其他能做的做完

对实际使用的影响很直接：你敢把它挂在后台跑了。它不会因为一个无关紧要的空字段卡住两小时，也不会在要命的决策上自作主张。

五、误操作与安全：敢放多大手

让 AI 碰你的电脑，最大的顾虑就是「它手滑怎么办」。两组数据：

安全指标 GPT-6 Astra 上代 GPT-5.6 Sol
电脑操作不当行为率 2.4% 22.0%
Honeypot 越界测试越界率 0% 48%

Honeypot（蜜罐）测试专门测「AI 会不会越权干没让它干的事」——Astra 是 0%，上代接近一半。误操作率 2.4% 大概是什么概念：填 100 个字段错 2 个，比大多数人手工录入的出错率还低。

但 practical 的建议还是循序渐进：

  • 第一阶段：只读任务（数据汇总、翻邮件整理信息）——零风险
  • 第二阶段：可撤销操作（写文档、填草稿、建日程）——错了能撤回
  • 第三阶段：对外发布类操作（发邮件、提交表单）——保留最后一步人工确认
  • 永远别一上来就给它：删除权限、支付操作、生产环境

七、什么人现在就该用

现在就该上车的：

  • 每天有大量重复性界面操作的：运营、销售支持、行政、财务
  • 用「没有 API 的老系统」的——内外部系统越老旧，Computer Use 优势越大

可以再等等的：

  • 任务全是纯文本对话的——用不到操作电脑，普通 ChatGPT 就够
  • 对数据保密性要求极高的——AI 操作界面意味着屏幕内容会被截屏上传，涉密环境别用
  • 任务链条里充满「说不清的判断」的——规则越模糊，2.4% 的误操作率越会被放大

FAQ 常见问题

Q1：Computer Use 是什么意思？
让 AI 像人一样操作电脑——看屏幕截图识别界面元素，自己移动鼠标、点击按钮、敲键盘，完成填表单、改文档、跑软件等完整任务，而不是只在聊天框里给你出文字答案。

Q2：AI 操作我的电脑安全吗？
误操作是最大风险点。Astra 在 OSWorld 2.0 测试中误操作率 2.4%（上代 22.0%），Honeypot 越界测试 0%。建议从低风险任务开始放手，涉及删除、付款、发送的操作保留人工确认。

Q3：和 Claude 的 Computer Use 有什么区别？

Q4：国内现在能用上吗？

Q5：什么工作最适合先交给它？
