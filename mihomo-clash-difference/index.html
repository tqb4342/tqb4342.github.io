Mihomo 是什么？Mihomo 和 Clash 有什么区别？（2026）

Mihomo 是 Clash 的社区分支内核，原名 Clash Meta，由 MetaCubeX 团队维护。原版 Clash 内核 2023 年停止维护后，Mihomo 成为事实上的继任者，完整兼容 Clash 配置，同时新增了 VLESS、Reality、Hysteria2 等新协议支持。现在你下载的绝大多数”Clash 客户端”，底层跑的都是 Mihomo 内核。

📚 本文是 Clash 完全教程（2026） 的支撑文章，聚焦”Clash 和 Mihomo 到底是什么关系”这一个点。客户端下载、订阅导入、规则配置，请看总览页。

一、为什么会有 Mihomo？Clash 停更简史

很多人第一次接触 Mihomo 是因为困惑：我明明下载的是”Clash 客户端”，为什么设置里全是 Mihomo 的字样？

故事要从 2023 年说起：

  • 2019-2023：Clash 由开发者 Dreamacro 维护，是最主流的规则型代理客户端内核，包含开源版和闭源的 Clash Premium
  • 2023 年 11 月：原作者删除了 GitHub 仓库并停止维护，原版 Clash 内核（含 Premium 闭源版）从此停更
  • 2023 年后：社区分支 Clash Meta 接棒，后正式更名为 Mihomo，由 MetaCubeX 团队持续维护至今（项目地址 github.com/MetaCubeX/mihomo，GitHub Stars 15K+）

结果就是：原版 Clash 只停留在支持 SS、VMess、Trojan 的”旧时代”，而 2024 年之后普及的新协议（Reality、Hysteria2、TUIC、WireGuard 等）全是 Mihomo 率先支持。机场订阅和客户端生态也随之整体迁移到了 Mihomo 内核。

二、Mihomo vs Clash：一张表看懂区别

原版 Clash 其实有两个版本：开源版（Dreamacro/clash）和闭源的 Clash Premium。2023 年删库后两者都停更了。下面把 Mihomo 和它们一起对比：

维度 Clash 开源版（已删库） Clash Premium（闭源，已停更） Mihomo（原 Clash Meta）
维护状态 2023 年删库停更 同步停更 持续活跃更新
开源状态 MIT 开源 闭源 完全开源（GPL）
协议支持 SS / VMess / Trojan + Snell + VLESS / Reality / Hysteria2 / TUIC / WireGuard / AnyTLS
规则引擎 基础 DOMAIN / IP 匹配 同开源版 规则集（Rule-Set）+ 脚本规则 + 逻辑规则
TUN 模式 基础 基础 增强：gvisor / system / mixed 三栈
DNS 基础 基础 fake-ip + 域名嗅探 + 按规则分流
策略组 基础 基础 增强（url-test / fallback / load-balance）
GitHub Stars 已删库 - 15K+
配置兼容 - - 完全兼容 Clash 原版配置

核心结论：Mihomo 是 Clash 的超集。原版 Clash 能跑的配置，Mihomo 都能跑；但 Mihomo 的新功能（Reality 协议、规则集、增强 TUN），原版 Clash 一个都没有。想系统掌握规则集、脚本规则的写法和分流配置，看 Clash / Mihomo 自定义规则完全指南。

三、你正在用的”Clash”其实都是 Mihomo

这是最大的认知误区。你以为自己用的是 Clash，实际上用的是 Mihomo：

客户端 内核 说明
Clash Verge Rev Mihomo 当前最推荐，Win/macOS/Linux 全平台
ClashMetaForAndroid（CMFA） Mihomo Android 首选
Spectre（iOS） Mihomo 内核 iOS 端基于 NetworkExtension
Clash for Windows（旧版） 原版 Clash 已停更，建议迁移
ClashX / ClashX Pro（macOS 旧版） 原版 Clash 已停更，建议迁移到 Verge Rev

怎么确认？打开客户端的”关于 / About”页面，看到 Mihomo 字样就是新内核。如果你还在用停更的老客户端，建议尽快迁移到 Clash Verge Rev，从 CFW 迁移的具体操作见 CFW 迁移到 Clash Verge Rev 教程。停更软件不支持新协议，长期用还有安全隐患。

四、Mihomo 客户端怎么选

Mihomo 是内核（引擎），真正操作界面的是客户端（外壳）。按平台选：

  • Windows / macOS / Linux：Clash Verge Rev，最活跃、功能最全，内置 Mihomo 内核，教程见 Clash Verge 教程
  • Android：ClashMetaForAndroid（CMFA），MetaCubeX 官方维护
  • iOS：Spectre 等基于 NetworkExtension 的客户端
  • 路由器 / 软路由：OpenClash（OpenWrt 插件）等，底层均为 Mihomo

进阶用户也可以直接从 MetaCubeX/mihomo GitHub 仓库 下载内核二进制部署（如 VPS 命令行环境），但新手建议先用带界面的客户端，配置门槛低很多。客户端选择、订阅导入、协议对比的完整指南，回到 Clash 完全教程。

五、Mihomo 相关的常见问题

Mihomo 需要单独安装吗？

不需要。主流客户端已经内置了 Mihomo 内核，装好客户端就能用。只有自己写配置、在服务器上部署时才需要单独下载内核。

我的机场订阅在 Mihomo 上能用吗？

能。Mihomo 完全兼容 Clash 原版配置，机场提供的订阅链接直接导入即可。现在绝大多数机场的订阅本身也是按 Mihomo 格式生成的。

Mihomo 和 Clash Verge 是什么关系？

Mihomo 是内核，Clash Verge Rev 是客户端外壳。类比：Mihomo 是发动机，Verge 是车身。发动机统一，外壳可以有很多个。

原版 Clash 还能用吗？

能用，但不建议。已停更两年多，不支持 Reality、Hysteria2 等新协议，无法适配机场新节点，且长期无安全更新。凡是还让你用原版 Clash 的教程，基本都过时了。

Clash Premium 和 Mihomo 有什么区别？

Clash Premium 是原版 Clash 的闭源增强版（多了 TUN 等功能），2023 年和开源版一起停更。Mihomo 是社区分支，完全开源，功能上是 Premium 的超集，且持续维护。现在没有理由再用 Premium。

Mihomo 收费吗？

不收费。Mihomo 是 GPL 开源项目，免费使用、自由修改。你看到的任何”付费 Mihomo”都是第三方二次封装的，不是官方行为。

Mihomo 什么时候从 Clash Meta 改名的？

2023 年下半年。早期项目叫 Clash.Meta，后为避免商标争议更名为 Mihomo。社区里两个名字混用，指的都是同一个内核。

七、总结

  • Mihomo = 原 Clash Meta = Clash 的社区继任者，现在的主流”Clash 客户端”底层都是它
  • 原版 Clash 2023 年 11 月删库停更，不支持新协议，建议迁移
  • Mihomo 完全兼容 Clash 配置，直接导入机场订阅即可用
  • 客户端推荐：桌面用 Clash Verge Rev，Android 用 CMFA，iOS 用 Spectre
