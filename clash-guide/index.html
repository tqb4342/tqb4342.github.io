一、什么是 Clash / Mihomo？

Clash 是什么？ 一句话：Clash 是一款开源、跨平台的规则型代理客户端，负责把机场订阅里的节点按规则分流、统一管理——机场负责”提供节点”，Clash 负责”如何使用节点”。

Clash 最初由开发者 Dreamacro 开源，2023 年后原作者停止维护，社区分支 Mihomo（Clash.Meta） 接棒，新增了对 Reality、Hysteria2 等新协议的支持，目前绝大多数在用客户端都基于 Mihomo 内核。想搞清楚 Mihomo 和 Clash 到底是什么关系、为什么你下载的”Clash”其实是 Mihomo，可以看 Mihomo 是什么？Mihomo 和 Clash 的区别。

它的工作原理可以概括为四步：

  1. 读取订阅（Profile）：从机场拿到一份订阅链接，客户端解析出节点列表与规则；
  2. 建立本地代理：在电脑/手机上起一个 HTTP/SOCKS 代理（默认 7890 端口）和一个 TUN 虚拟网卡；
  3. 按规则分流：根据规则把不同流量导向”代理节点”或”直连”；
  4. 转发流量：命中代理规则的流量被发往墙外节点，其余直连。

一句话理解：Clash 是你和被封锁网站之间的智能调度器——它和”一键 VPN”最大的区别，就是把”订阅管理、节点选择、规则分流、TUN 透明代理”整合在一个客户端里，按需精细控制。

四、机场订阅：获取与导入

「机场」是圈内对提供 Clash/V2Ray 订阅的商业代理服务的俗称。选机场比选客户端更关键——节点质量、线路类型、售后跑路风险都取决于它。

标准导入流程：

  1. 在机场后台的「订阅」页，复制 Clash 订阅链接（通常是 https://xxx/...&flag=clash 形式）；
  2. 打开客户端 → 订阅管理 → 粘贴链接 → 点击「更新/Update」；
  3. 节点列表出现后，选一个节点，开启「系统代理」或「TUN 模式」即可上网。

免费机场普遍不稳定且存在隐私风险，长期使用建议选有口碑的付费服务。

五、核心机制：规则分流 + TUN 模式

这是 Clash 区别于”一键 VPN”的核心能力。

规则分流（Rule） 按匹配条件决定每条流量的去向，常见规则类型：

  • DOMAIN-SUFFIX（域名后缀，如 google.com）
  • DOMAIN-KEYWORD（域名关键词）
  • IP-CIDR / GEOIP（IP 段 / 国家地区）
  • PROCESS-NAME（进程名，可针对特定 App）

典型策略是：国内域名直连、海外域名走代理、广告域名拦截。相比全局代理，规则分流速度更快、更省流量，也不会让国内视频/网银被迫绕路。

TUN 模式 通过虚拟网卡接管系统全部流量，解决部分 App（如命令行工具、Docker、某些游戏）不走系统代理的问题。代价是开销略高，一般按需开启——日常浏览开「系统代理」即可，遇到个别 App 不走代理再开 TUN。想深入了解 TUN 原理、各客户端开启步骤与常见坑，看 Clash TUN 模式完全指南。

协议决定流量如何被伪装、加密与传输，直接影响速度与抗封锁能力。Mihomo 内核目前支持以下主流协议（在 config.yaml 里用 type 字段指定）：

七、配置文件与 Profile

Clash 的核心配置是一个 config.yaml，三大块：

  • proxies：节点定义
  • proxy-groups：节点分组（如「自动选择」「故障转移」「手动」）
  • rules：分流规则

机场订阅本质就是一份”托管配置”，客户端定期拉取更新。你也可以在订阅基础上叠加本地配置或托管规则集（rule-provider），实现更精细的控制。下面是一份简化示例，帮你快速理解结构：

mixed-port: 7890          # 本地混合代理端口
mode: rule                # 规则模式（另一选项 global=全局代理）

proxies:
  - {name: "节点A", type: ss, server: example.com, port: 443, cipher: aes-256-gcm, password: "xxx"}

proxy-groups:
  - name: "🚀 节点选择"
    type: select           # 手动选择
    proxies: ["节点A", "自动选择", DIRECT]
  - name: "自动选择"
    type: url-test         # 按延迟自动测速选最快
    proxies: ["节点A"]
    url: "http://www.gstatic.com/generate_204"
    interval: 300

rules:
  - DOMAIN-SUFFIX,google.com,🚀 节点选择
  - GEOIP,CN,DIRECT        # 国内 IP 直连
  - MATCH,🚀 节点选择       # 兜底：其余走代理

看懂这个结构，你就理解了 Clash 的运作逻辑：proxies 提供节点 → proxy-groups 把节点组织成可切换的组 → rules 决定每条流量用哪个组。想从零配置上手，看保姆级教程：

九、排障指南

最常见的 Clash 故障、成因与快速解法：

  • 节点全红 / 连不上：订阅过期、节点被封、本地时间错误。→ 先点「更新订阅」，再换节点；检查系统时间是否自动同步（时区/时间不对会导致 TLS 握手失败）
  • 能连但打不开网页：系统代理未生效、DNS 泄露。→ 确认客户端「系统代理」已开启；开启 TUN 模式通常能解决 DNS 泄露
  • 部分 App 不走代理：未开 TUN 模式。→ 开启 TUN（虚拟网卡接管全部流量），命令行/Docker/游戏类 App 最常遇到
  • 速度慢：节点负载高、线路类型不佳。→ 换用 IPLC/IEPL 专线节点，或换「自动选择」组让它按延迟选最快节点

十二、FAQ 常见问题

Q1：Clash 是什么？
Clash 是一款开源跨平台规则型代理客户端，现由社区分支 Mihomo 维护。它本身不提供节点，而是读取机场订阅、按规则把流量分流到不同节点或直连，是当前最主流的科学上网前端工具。

Q2：Clash for Windows 和 Clash Verge 有什么区别？
Clash for Windows 是经典客户端但已停止维护；Clash Verge（Rev）用 Rust/Tauri 重写、性能更好、持续更新（GitHub 28k+ star），是目前最推荐的选择。两者核心功能一致，均支持订阅导入与规则分流。详见 客户端对比。

Q3：Clash 订阅怎么导入和使用？
在机场后台复制”Clash 订阅链接”，打开客户端进入”订阅管理”粘贴并更新，节点列表即出现。选节点、开启系统代理或 TUN 模式即可上网。新手可看 Clash 保姆级教程。

Q4：Clash 规则分流是什么？和全局代理有何不同？
规则分流按域名/IP/地区等规则，自动决定流量走代理还是直连（如国内站点直连、海外站点代理），速度更快也更省流量；全局代理则所有流量都走节点。详见 规则分流一节。

Q5：Clash 节点协议怎么选（Vmess / VLESS / Trojan）？
Trojan/Reality 伪装成正常 HTTPS、抗封锁最强，首选；VLESS 轻量快速；VMess 经典但特征较明显；Hysteria2 弱网速度快。一般机场订阅已配好，无需手动选。详见 协议详解。

Q6：Clash 连不上 / 节点全红怎么办？
多为订阅过期、节点被封或本地配置问题。先更新订阅、切换节点，再检查 TUN/系统代理是否开启、系统时间是否正确。按 Clash 排障指南 逐项排查。

Q7：Clash 和 V2RayN 有什么区别？
两者都是代理前端。Clash 强在规则分流与多协议统一管理、配置更直观；V2RayN 更贴近 V2Ray 内核、可调参数更细。多数机场用户更习惯 Clash 的图形化体验。

Q8：手机端 Clash 用什么客户端？
Android 用 ClashMetaForAndroid（CMFA）；iOS 因系统限制需用 Shadowrocket 或 Stash（付费）。配置思路与电脑端一致：导入订阅→选节点→开启代理。详见 各平台教程。
