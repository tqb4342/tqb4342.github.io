挂梯子是什么意思？怎么挂梯子（2026 电脑/手机保姆级教程）

2026-11-14 科学上网 2.6k 字   
阅读量 --
科学上网 翻墙 Clash 梯子 挂梯子

第一次搜「挂梯子」的人，大概率是听同事或网友说了句「你得先挂个梯子」，然后一头雾水：梯子是什么、去哪弄、挂上之后干什么。这篇就是写给这个阶段的：从黑话扫盲到每台设备具体怎么挂，一步一步来，不跳步。

30 秒速答

  • 挂梯子是什么意思：梯子是翻墙工具的黑话，「挂」就是连上——让电脑或手机通过境外服务器中转，访问国内直连不了的网站
  • 挂梯子要几样东西：两样。一个装在设备上的客户端软件（免费），一条机场订阅（花钱），先有梯子再谈挂，怎么搞到看第二节
  • 各设备挂法：Windows / Mac 装 Clash Verge，安卓装 ClashMeta for Android，iPhone 先解决外区 Apple ID 再装 Spectre；从零起步的完整流程看 Clash 完全教程
  • 挂上还是上不了网：先更新订阅、再看系统代理开关、再换节点，三分钟自查流程在第八节

一、「挂梯子」到底是句什么黑话

先把这个词拆开。梯子，指一切能帮你翻到墙外的工具：VPN、机场订阅、自建节点，圈内都笼统叫梯子。这个叫法的来历很直白——墙挡着你，梯子帮你翻过去。挂，就是把它用起来的动作：软件装好、节点连上、代理打开，这三步做完就叫「挂上了」。

所以「怎么挂梯子」这个问题，本质上是三件事的串联：搞到一条梯子（机场订阅或自建节点）、装一个能吃下这条梯子的客户端、把客户端和系统接通。网上很多教程一上来就教装软件，跳过了第一步，结果软件装完了没节点可用，这是新手最常见的卡点。

还有一个概念先分清：梯子不是软件本身。软件（Clash Verge、Shadowrocket 这些）只是播放器，梯子（订阅里的节点）才是内容源。明白了这个分层，后面的每一步都不迷糊。

二、挂梯子之前，先搞到手一个梯子

手里没梯子，装什么软件都白搭——这一环绕不过去。获取方式就两条路。

第一条路：买机场订阅（多数人的选择）。 机场就是专门卖节点服务的商家，你付月费，它给你一条订阅链接，里面是几十上百个境外节点。挑机场的完整方法论（线路类型、倍率、跑路预警）在 机场怎么选的避坑清单 里，这里只说结论式推荐：我用的是一枝红杏，用了两年多，日常看视频和 AI 工具都够稳，注册入口在 一枝红杏官网，Lite 档年付 99 元（每月 100G 流量），合每月 8 元出头，新用户先试用再决定。买完你会拿到一条以 https 开头的订阅链接，这条链接就是你的梯子，收好。机场后台长下图这样，每类客户端都有对应的订阅按钮，点开一键复制：

第二条路：自己搭。 买一台境外 VPS，自己装协议、自己维护，入门线路每月 5 美元左右（约 35 元）、隐私性更好，但要求你能看懂命令行、愿意处理证书和封端口这些琐事。愿意折腾的看 自建机场教程，零基础先不推荐，卡在半路是最难受的。

两条路的取舍展开对比（适合谁、长期成本、翻车率）在 科学上网方案对比 里，拿不准的先看那篇再回来。

三、Windows 怎么挂梯子

三步：

  1. 装客户端：下 Clash Verge Rev，只认 GitHub 官方仓库 的 Releases 页下载，搜索引擎里搜到的「Clash 官网」基本都是山寨。Windows 机器认准文件名带 x64-setup 的安装包，ARM 芯片的机器才选 arm64。山寨长什么样？下图这种第三方下载站就是典型：文件名跟官方一模一样，旁边混着个「-Chinese」后缀的中文版——官方从没发过中文特别版，多出来的东西就是别人塞进去的：


2. 导入订阅：打开软件 → 配置 → 粘贴你的机场订阅链接 → 更新，节点列表刷出来就算导入成功
3. 打开代理：主界面打开「系统代理」开关，再在代理页选一个节点，节点图标变绿就挂上了

验证方式：浏览器打开 google.com，能出页面就是挂上了。Windows 的完整图文流程在 Windows 科学上网教程 里，包括 Win10/Win11 的差异和防火墙的坑。

四、Mac 怎么挂梯子

流程和 Windows 一致：同样是 Clash Verge Rev（macOS 版），同样导入订阅、开系统代理。Mac 上要留意的是代理设置的位置：Clash Verge 开「系统代理」时会自动改系统设置，如果你手动去「网络 → 代理」里改过，记得别双重设置。装完第一次使用如果浏览器不开网页，检查一下系统代理端口和软件里的是否一致。

五、安卓怎么挂梯子

安卓的挂法和电脑略有不同，客户端换了，但「导入订阅 → 选节点」的骨架一样：

  • 客户端选 ClashMeta for Android 或 v2rayNG，都在 GitHub 开源免费，下载入口和对比在 安卓翻墙客户端清单 里
  • 导入方式支持粘贴订阅链接，也支持扫码，手机上扫码比打长链接方便得多
  • 安卓客户端打开后大多直接接管系统 VPN 通道，不需要像电脑那样单独开「系统代理」开关

一个安卓特有的坑：国产 ROM（华为、小米这些）的省电策略会杀后台，挂梯子的客户端被杀掉网就断了，记得把客户端加进电池优化白名单；更省事的一招是在最近任务卡片上下拉加锁，锁住的应用省电策略杀不掉。

六、iPhone 怎么挂梯子

iOS 是所有设备里门槛最高的，倒不是要花多少钱，而是主流客户端基本只在外区 App Store 上架，光下载这一步就先卡一道 Apple ID。顺序是：

  1. 先搞一个外区 Apple ID（美区最省心），不用充值，只是切账号，完整流程在 iPhone 科学上网教程 里
  2. 装 Spectre 或 Shadowrocket（Spectre 免费；Shadowrocket 2.99 美元一次买断，按需选一个）
  3. 导入机场订阅 → 打开连接开关 → 节点选中，挂上

iPhone 挂梯子之后顶部会出现 VPN 字样，这是正常状态，不是异常。

七、电视、路由器这些设备怎么办

电视和电视盒子自己装客户端不现实，两条路：一是投屏（手机挂好梯子后投到电视，最简单），二是把梯子挂到路由器上，全家设备无感翻墙。第二条路适合有软路由或刷机路由器的人，涉及 OpenClash 或梅林固件，整套流程在 路由器挂梯子教程 里。游戏主机（PS5、Switch）同理，要么挂路由器，要么改 DNS 凑合。

八、挂上之后上不了网？三分钟自查

按这个顺序查，命中率从高到低：

  • 订阅过期：机场节点列表是会变的，订阅三五天不更新就可能出现「软件开着、节点全红」。去客户端里手动更新一次订阅
  • 系统代理没真打开：Windows 看 Clash Verge 的系统代理开关是否是开的，Mac 去系统设置确认。开关显示开着但没生效，重启客户端一次
  • 节点本身挂了：换一个节点再试，晚高峰个别节点拥挤很正常，换到延迟低的节点即可
  • DNS 被污染：前三种都排除了还打不开网站，大概率是 DNS 的问题，处理方法在 Clash DNS 配置教程 里

FAQ 常见问题

挂梯子是什么意思？

梯子是翻墙工具的黑话，指 VPN、机场这类能访问境外网络的工具；挂梯子就是让设备连上梯子——装好客户端、导入节点订阅、打开系统代理，三步做完就等于挂上了。挂上之后 Google、YouTube、ChatGPT 这些国内直连不了的网站就都能打开。

免费梯子能用吗？

短期能凑合，长期别指望。免费公共节点晚高峰拥挤、随时失联，还有被记录流量的风险。日常稳定使用建议机场订阅，月付十几元起，大部分机场有试用额度，先试用再付钱。想省钱且动手能力强，可以看站内的自建机场教程。

苹果手机怎么挂梯子？

iOS 的门槛不在钱在下载：主流客户端（Spectre 免费、Shadowrocket 2.99 美元买断）只在外区 App Store 上架，所以先准备一个外区 Apple ID，再装客户端，最后导入机场订阅。外区 Apple ID 的获取流程在站内 iPhone 科学上网教程里。

挂上梯子之后上不了网怎么办？

按顺序查三样：一是订阅是不是该更新了（节点信息过期是头号原因）；二是系统代理有没有真打开，Windows 看 Clash Verge 的系统代理开关，Mac 看系统设置里的代理状态；三是当前节点是不是挂了，换个节点再试。三步走完还不行，再查 DNS 设置。

梯子、VPN、机场是一回事吗？

不是一回事但经常混着说。VPN 原本指虚拟专用网络技术；梯子是黑话，泛指一切翻墙工具；机场是卖节点订阅的服务商。日常语境里说挂梯子，大概率指的是装客户端加买机场订阅这套组合。

换设备要重新买梯子吗？

不用。机场订阅按条卖不按设备卖，同一条订阅可以导入你所有的设备：电脑、手机、平板同时挂同一个订阅没问题，大部分机场限的是同时在线设备数，一般 2 到 5 台起步。
